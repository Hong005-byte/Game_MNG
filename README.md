# Tycoon Idle

一个用 C++20 + SFML 3 写的小镇经营 / 人生模拟游戏。一边在小镇里走动、盖产业、跑腿做小游戏,一边有一套完整的经济/生活模拟系统在背后持续运行——就算不在游戏窗口里,回来时也会自动补算离线期间的进度。

支持中英双语(启动时选择),两种玩法界面:经典控制台菜单,或者可以用 WASD/方向键+鼠标走动点击的图形化小镇视角——图形化视角是像素风的 HD-2D 3D 镜头(带光影/泛光的立体建筑,而不是纯平面贴图),9 个服务类建筑(职介所、钱庄、旅馆、厨房、市政厅、集市、诊所、仓库、商铺)和多个原材料/加工产业都有各自手工设计的外观。

## 下载

去 [Releases](https://github.com/Hong005-byte/Game_MNG/releases) 页面下载最新的 `TycoonIdle-vX.X.X-win64.zip`,解压后直接运行 `Game Mng.exe`——是免安装的便携版,不需要额外装任何运行库。游戏内建了自动更新检测,有新版本时会提示。

仅支持 Windows。

## 玩法概览

- **经营**:一棵完整的产业树,从原材料(农场、矿场、渔港……)到多层加工品,雇员工、请工人、专精产业,滚雪球式发展经济。部分产业要同时消耗好几种材料才能加工(比如蛋糕坊要蜜糖+牛奶+小麦),配方可以在游戏内的"配方图鉴"面板里按图查。
- **建造系统**:只有农场、伐木场、采石场、矿场是免费秒建的,其余产业都要先攒够现金和建材(木板、砖块、铁锭……)才能开工,还要再等 3~5 个游戏日的工地施工——地图上能直接看到"空地告示牌 / 施工中的工地 / 建成后的成品"三种状态,材料不够也可以中途取消建造拿回一半。
- **港口与渔人岛**:在海港区花一大笔钱建成港口、再造一艘船,就能出海前往渔人岛——一个专注捕鱼、能捞到更多鱼种的独立地图,回程在岛上的渡船直接传送回港口。
- **人生模拟**:角色会变老、会饿、会累、会生病——睡觉恢复体力并获得"精神饱满"加成(卧室可以花钱升级,加成更强更持久,还能降低生病概率)、吃饭恢复饥饿(换着吃不同食物能拿"饮食多样化"额外加成)、生病了要看医生,长期忽视是会死的。就算把游戏整个关掉不管,离线期间的忽视也不会被无声无息地写死——顶多卡在鬼门关前,回来第一时间会有醒目提示提醒你赶紧处理。角色去世后传承点数会留给下一代,带着小幅永久加成重新开始。
- **四季系统**:春夏秋冬每季 30 个游戏日(1 个月一季,一年 4 个月),不只是好看——春天不容易生病、夏天体力消耗更快、秋天全产业产出小幅提升、冬天饥饿消耗更快且更容易生病;换季时还有色块过场动画和对应的氛围粒子(飘雪、落叶、花瓣、热浪),每种季节的粒子样式都不一样。
- **市场**:低买高卖,价格会随时间和你自己的交易/生产波动,部分商品在当季需求旺盛时能卖更高价;仓库面板能直接看到当前库存清单。
- **成就 & 传承**:28 个成就,解锁时屏幕左下角会弹出提示(配合音效),还给现金奖励;死亡后传承点数可以买永久加成,其中一条能专门削弱冬季的额外惩罚。
- **暂停菜单**:随时按 Esc 存档、调音量、切换分辨率/全屏、自定义按键。

详细玩法说明在游戏内的"How to Play / 玩法"面板里,比这里写得全。

## 从源码编译

需要 Visual Studio 2022+(含 C++ 桌面开发工作负载)和 [vcpkg](https://github.com/microsoft/vcpkg)。

```bash
git clone https://github.com/Hong005-byte/Game_MNG.git
cd Game_MNG
```

依赖(SFML 3)通过 `Game Mng/vcpkg.json` 的 manifest 模式管理,用 Visual Studio 打开 `Game Mng.slnx` 编译时会自动安装,首次编译会因为要拉取/编译 SFML 而比较慢。也可以手动跑一次：

```bash
vcpkg install --triplet x64-windows --x-manifest-root="Game Mng"
```

编译产物在 `Game Mng/x64/Release/`(或 `Debug/`),同目录下已经有编译脚本会自动把所需的运行时 DLL 拷贝过去。

## 项目结构

- `Game.h/.cpp` —— 核心经济/人生模拟状态机,两套界面(控制台菜单 / 图形化世界)共用同一份状态
- `GameWorld.h/.cpp` —— 图形化小镇视角:渲染、输入、小游戏、所有窗口内的 UI 面板
- `Business.h/.cpp`、`Market.h/.cpp`、`Staff.h/.cpp`、`Life.h/.cpp`、`Events.h/.cpp`、`Achievements.h/.cpp` —— 各自独立的子系统
- `Localization.h/.cpp` —— 中英文字符串表
- `SaveManager.h/.cpp`、`Settings.h/.cpp` —— 存档(按角色)与玩家偏好(音量/按键/分辨率,跨存档共用)的持久化
- `UpdateChecker.h/.cpp`、`Version.h` —— 启动时后台查询 GitHub Releases 是否有新版本
